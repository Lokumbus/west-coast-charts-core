# WestCoast Charts — Free Core 1.1.1-rc.7

MIT-licensed JavaScript chart distribution, including commercial use. No account, payment or licence key is required. This is a release candidate, not a stable-version claim.

## Install

Install the public GitHub release asset with npm:

```sh
npm install https://github.com/Lokumbus/west-coast-charts-core/releases/download/v1.1.1-rc.7/west-coast-charts-1.1.1-rc.7.tgz
```

Or install the exact public Git tag:

```sh
npm install github:Lokumbus/west-coast-charts-core#v1.1.1-rc.7
```

```js
import WestCoastCharts from 'west-coast-charts/full'
const chart = new WestCoastCharts(document.querySelector('#chart'), {
  chart: { type: 'bar', height: 360 },
  series: [{ name: 'Requests', data: [24, 38, 31, 52] }],
  xaxis: { categories: ['Mon', 'Tue', 'Wed', 'Thu'] }
})
await chart.render()
```

Download the release archive and open example.html for an entirely local example. The full build contains **Core and free plugins only**. The main/core entry is leaner; import a free type or feature explicitly as needed. Bundlers support ES modules and CommonJS. No install or prepare script executes.

The npm registry name is reserved in package metadata for compatibility. **A registry publication is not implied:** the GitHub asset/tag installation above works independently of registry authentication. A registry version will be announced only after actual publication verification.

## What is included

- Unmodified Core/full UMD, ES module and CommonJS distributions.
- Free chart-type and feature modules, locales and shared TypeScript declarations.
- MIT option validator / chart-describe helpers and the matching RC7 schemas, usable via `west-coast-charts/agent/validate`, `west-coast-charts/agent/describe` and `west-coast-charts/schema/wcc-options.schema.json`.
- Original MIT licence, notices and third-party attributions.
- Per-file integrity/provenance and a local example.

Shared declarations and schemas describe optional Premium options too; they are API vocabulary, **not included Premium renderers or exports**. Runtime tier support must be checked separately from schema validation. No Premium/layer/map bundle, private repository history, commercial contact text, signer, key or Commerce service is included. This repository is a distribution repository, not the complete source/build tree.
