# WestCoast Charts Free Core 1.1.1-rc.9

MIT, including commercial use. No account or key required. This is a prerelease distribution.

Install the exact Core version with npm:

```sh
npm install west-coast-charts@1.1.1-rc.9
```

Alternatively, install the versioned GitHub release asset:

```sh
npm install https://github.com/Lokumbus/west-coast-charts-core/releases/download/v1.1.1-rc.9/west-coast-charts-1.1.1-rc.9.tgz
```

For an offline installation use `npm install ./west-coast-charts-1.1.1-rc.9.tgz`.

Use `import WestCoastCharts from 'west-coast-charts/full'` for Core and all free plugins, or the lean `west-coast-charts/core` plus explicitly imported types/features. The UMD browser build is `dist/west-coast-charts.full.min.js`; open example.html locally. CommonJS and ES modules are supplied.

MIT validation and describe helpers are exported as `west-coast-charts/agent/validate` and `west-coast-charts/agent/describe`, with matching schemas under `west-coast-charts/schema/*.json`. Shared declarations/schemas include optional Premium vocabulary; no Premium renderer or Premium export is included.

No Premium/layer/map bundles, repository history, commercial contact text, signer, credentials or commerce service are included. This is a ready-built distribution, not the full source/build repository. Preserve LICENSE, NOTICE and THIRD-PARTY-LICENSES.txt. All imported files are byte-identical to commit b6f323a10ea2378d39c7d894af9372f690cfff82; PROVENANCE.json lists them.
